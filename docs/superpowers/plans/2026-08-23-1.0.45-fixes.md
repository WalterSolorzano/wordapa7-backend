# WordAPA7 1.0.45 — Plan: Resolver crashes, documento intocable, add-in, menú contextual

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminar los 10 fallos reportados por el usuario: crash/navegación al resolver citas, export colgado, portada modificada, mapa duplicado/feo, preview desbordado, editor de portada erróneo, procesos WINWORD huérfanos, complemento invisible, click derecho sin "Convertir", y UI gigante donde esperaba una chica.

**Architecture:** Dos pivotes grandes: (1) **edición in-place** — nueva ruta de export que abre el `.docx` original con python-docx y modifica SOLO los párrafos del cuerpo, dejando portada/secciones/headers byte-idénticos (python-docx preserva partes no tocadas, confirmado en docs oficiales); (2) **instalación de complemento por catálogo confiable + purga total Wef**, el método desktop confiable según Microsoft Learn. El resto son fixes quirúrgicos con tests.

**Tech Stack:** React 18 + TS + Zustand; FastAPI + python-docx; NSIS; registro HKCR/HKCU.

- Vitest SIEMPRE con `--pool=forks --poolOptions.forks.singleFork`.

- NUNCA matar procesos WINWORD que no hayamos creado nosotros (PID-scoped only).

- No push a master. Commits convencionales.
- Logs obligatorios vía `wordapa7_logger.log_event` en cada fix de backend.

## Riesgos

| Riesgo | Mitigación |
|---|---|
| In-place no cubre headings nuevos/reordenados | Si el doc requiere inserciones (portada sintética, TOC), caer automáticamente a rebuild con aviso; in-place es para el caso mayoritario "formatear mi doc" |
| TrustedCatalog local sin share UNC quizá no liste | Fallback documentado: ruta UNC `\\localhost\<share>` creada por installer (`net share`) — task incluye creación de share con permiso solo-lectura al usuario |
| Verbo estático oculto en Win11 moderno | Aceptado temporalmente; stretch: sparse MSIX IExplorerCommand |

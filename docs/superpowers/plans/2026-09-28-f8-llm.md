# F8 — Los tres cables de LLM: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que los 13 proveedores del catálogo funcionen de punta a punta, y que los 9
campos de modelo dejen de ser controles mudos.

**Architecture:** Tres cables sueltos, en orden de daño. (a)
`proactive_auditor.refine_with_llm` **no pasa por el router**: llama a NIM con
`requests.post` **síncrono dentro de un `async def`**, con el modelo **quemado**, y su
consumidor lee `os.getenv("NVIDIA_API_KEY")` en vez del request. Es el **único motor de
ortografía del producto** y no funciona para ninguno de los 5 proveedores que el repo
declara vivos. (b) Las **9 variables de modelo** las ofrece la UI, las valida, las guarda,
y **admite por escrito que no llegan**: `main.py:970-984` es un `dict` de variables de
**clave**, no una allow-list de modelos. (c) `api_key` se inyecta en `nvidia_nim` sin
importar de qué proveedor venga (`llm_classifier.py:113`), y **17 de 18 endpoints ignoran
`provider_id`**.

**Tech Stack:** Python 3.11, `httpx`, FastAPI, Pydantic, pytest, React/TS.

**Spec:** `docs/superpowers/specs/2026-09-27-rediseno-superficies-master-design.md` §12.

## Review Focus

1. **Un usuario con ZenMux, Aion, Kilo, Ollama o HF abre un documento.** Hoy obtiene
   **cero refinamiento de ortografía**, porque `refine_with_llm` lee
   `os.getenv("NVIDIA_API_KEY")` y no hay key. El test tiene que afirmar que, con la key de
   **cada** uno de los cinco, el motor corre. → Task 1
2. **El refinamiento bloquea el event loop.** `requests.post` **síncrono** dentro de un
   `async def` detiene **todo** el backend mientras la red contesta. El test tiene que
   afirmar que dos llamadas concurrentes se solapan en el tiempo, no que se serializan. → Task 1
3. **Elegís Groq y se rompe NVIDIA.** `api_key` va a `nvidia_nim` sin mirar de qué
   proveedor viene → 401 → **cooldown de 600 s**. El test tiene que afirmar que la key de
   Groq **nunca** llega al cliente de NVIDIA. → Task 3
4. **Elegís un proveedor y no lo respeta.** 17 de 18 endpoints ignoran `provider_id`. El
   test tiene que recorrer **los dieciocho** y afirmar que todos lo reenvían. → Task 3
5. **La key de HuggingFace nunca llega al backend.** Falta en `backend.ts:341-355`, en
   `main.py:970-984` y en `ai_keys.py:18-32`. El test tiene que afirmar que **las 14 claves
   del catálogo** llegan a `os.environ`, una por una, y que la lista coincide con el
   catálogo. → Task 2

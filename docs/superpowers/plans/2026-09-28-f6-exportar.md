- [ ] **Step 3: El backup**

Antes de `shutil.copy2`, en **las dos ramas** (COM y fallback) — o mejor, **una sola vez,
antes de la rama**, para que no haya dos caminos que se puedan olvidar:

```python
def _backup_de(dest: Path) -> Optional[Path]:
    """Copia de seguridad del archivo que se va a pisar.

    El primer principio del producto dice no romper jamás el trabajo del
    estudiante, y un write-back sin vuelta lo rompe. El backup se escribe una
    sola vez: el segundo write-back del mismo archivo no crea un segundo backup
    ni pisa el primero, que para entonces ya sería el contenido generado.

    El nombre es `<archivo>.docx.bak`, junto al original: donde el usuario lo
    va a encontrar. Devuelve None si ya existía.
    """
    backup = dest.with_name(dest.name + ".bak")
    if backup.exists():
        return None
    try:
        shutil.copy2(str(dest), str(backup))
    except OSError:
        return False   # no se pudo: el endpoint tiene que abortar
    return backup
```

**El `False` es lo importante**: si el backup no se pudo escribir, **la operación se
cancela**. Devolver `None` (ya existía) y `False` (falló) tiene que ser distinguible, o
el endpoint no puede decidir.

Y **decíle a la persona**: la respuesta del endpoint incluye `backup: "<ruta>" | null`.

## Self-Review

**1. Cobertura del spec §10.** La tarea 6.0 (backup y cambios sin guardar) es lo que el
spec §10 marca como **obligatorio antes que todo lo demás**, y es Task 1 y Task 2. El
`format` al store es Task 3. El panel de ajustes avanzados es Task 4.

**2. El orden importa y está justificado.** Una fase que empieza por el panel bonito y
deja el write-back sin backup para el final es una fase donde la parte peligrosa es la
que se apura. **El spec §10 lo dice explícitamente y este plan lo respeta.**

**3. Lo que este plan no arregla.** Las claves de los proveedores en texto plano
(`localStorage`, IndexedDB, `ai_keys.json` sin `chmod`) quedan para la F8 **anotadas**,
no resueltas: es un rediseño del canal de secretos y nadie lo pidió.

**4. Placeholders.** El test de Task 1 tiene un `...` en el segundo caso y el
